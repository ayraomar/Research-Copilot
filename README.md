## 📖 Project Overview
Research Copilot is a digital assistant designed to democratize access to academic research by automating the analysis of static PDF documents. The system aims to mitigate the "manual latency" of traditional research workflows by providing structured insights, citation visualization, and conversational support.

## ⚙️ SDLC: Requirements Analysis
We have successfully completed the Requirements Analysis phase. Our findings are documented in the Software Requirements Specification (SRS), which defines the system's core functional objectives.

## ✨ Key System Objectives
- **Automated Paper Analysis:** Extraction of metadata, key findings, and limitations from PDFs.
- **Contextual Discovery:** Categorization of literature into Supporting, Conflicting, and Related studies to validate claims.
- **Conversational Interface:** A chatbot designed to clarify jargon and answer queries based on the uploaded source.
- **Visual Mapping:** Interactive citation graph rendering.

## 🖇️ System Modeling
To bridge the gap between requirements and design, we have developed the following architectural models:
- **Context Diagram:** Illustrates the system's interaction with the user and external research paper databases.
- **Use Case Diagram:** Defines the functional boundaries of the system, including user authentication, PDF parsing, and categorical filtering of research.
